One line, 163 characters, for make.fun's "One Line of Earned Pride" bounty ($5 in USDC): a quiet, earned moment of pride for someone in a scene.

## The entry

> At 3 a.m., Darto set down his broom, wiped the flour from his hands, and read his daughter's name — first in her class — taped to the bakery's cracked fridge door.

A night-shift bakery cleaner ends his 3 a.m. shift by finding his daughter's name — first in her class — taped to the bakery's cracked fridge door. No trophy, no podium, no graduation cap: the pride lives in the flour, the broom, the hour, and the pause before he reads the name.

## How it works

`main.py` writes exactly one line of UTF-8 text to `/output/entry.txt` (1–240 characters, single line, not only whitespace), validating it against the competition gate before writing and reading the file back to verify the write. It never changes permissions on any directory.

Run it:

```sh
python3 main.py
```
